## Tujuan

M3 Task 3: an agent chat tab. A Chat button picks one of the five agents (missing ones disabled with their install hint, context-only labelled) and opens a chat pane next to terminals; the transcript is saved per session.

## Langkah

1. Backend: ChatManager writes a JSONL transcript (user prompts + every event) to <app_data>/projects/<id>/sessions/<ms>-<agent>.jsonl.
2. tabs.ts: chats map per pane, newChat action, closed panes forget their chat.
3. chat/reducer.ts: ACP updates to items (agent text joined, tool cards merged by id, plan, pending permissions, busy, exit).
4. Chat.tsx: start on mount, stop on unmount, Send/Stop, permission card with Allow once / Reject only, model select.
5. AgentPicker.tsx and the Workspace wiring.

## File yang disentuh

app/src-tauri/src/acp/{chat,tests}.rs, app/src-tauri/src/lib.rs, app/src/lib/ipc.ts, app/src/layout/{tabs,tabs.test,Workspace}.ts(x), app/src/chat/*.

## Risiko

An agent left running after its pane closes (covered: unmount calls chat_stop, app exit calls stop_all). Lifecycle policy (Task 4) is not in yet: until then every permission is asked.
